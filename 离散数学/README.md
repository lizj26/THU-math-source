# 离散数学

自动化系等院系的必修课。需要注意，本仓库收集的是**自动化系**开设的离散数学，其教学体系与计算机系开设的离散数学（1）（2）并不相同，两者不要混用。

当前收集的是**赵虹**老师班级的课堂讲义，共 33 份，见 `离散数学（自动化系）/讲义`：

* **L1 图论**：图的基本概念、通路与回路、连通性与连通度、图的矩阵表示、欧拉图、哈密顿图、树、平面图、图的着色问题。
* **L2 数理逻辑**：命题与联结词、命题公式与真值表、等值式、范式、联结词的完备集、推理形式与推理演算、一阶逻辑命题符号化、一阶逻辑公式、等值式与前束范式、推理理论。
* **L3 集合与关系**：集合概念与运算、基本集合恒等式、有序对与卡氏积、二元关系及其运算与性质、关系闭包、等价关系与划分、序关系、函数。

当前缺失：

* 该课程的往年考题与参考答案；
* 计算机系离散数学（1）（2）的资料。
